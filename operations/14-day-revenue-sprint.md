# 14-Day Revenue Sprint

Goal: one paid AI Workflow Audit or five serious leads.

## Day 1

- Review `brand/identity.md`.
- Review `offers/ai-workflow-audit.md`.
- Open `site/index.html` in a browser.
- Add payment link placeholder note if a QR code or link is available.

## Day 2

- Publish the repo to GitHub.
- Share `proof/ai-workflow-audit-checklist.md`.
- Add the GitHub link to the service page if available.

## Day 3

- Post Zhihu/Xiaohongshu draft 1.
- Reply to 5 relevant Reddit or founder-community threads.
- Track every reply in `leads/lead-tracker.csv`.

## Day 4

- Post Zhihu/Xiaohongshu draft 2.
- Improve README based on any questions people ask.
- Offer a first-client discount only if someone has a real workflow to audit.

## Day 5

- Post Zhihu/Xiaohongshu draft 3.

## Day 6-7

- Answer 10 relevant community threads total.
- Send direct replies only when people ask for help.
- Follow up with anyone who responded.

## Day 8-10

- Package the OpenClaw/ClawHub skill template if publishing is available.
- Create one short demo showing how an audit turns messy input into next steps.
- Ask warm contacts if they know one founder with a messy AI workflow.

## Day 11-14

- Focus only on conversion:
  - follow up serious leads
  - offer the RMB 699 audit
  - deliver one discounted audit if needed for proof
  - ask for permission to publish anonymized before/after

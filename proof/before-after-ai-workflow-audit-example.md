# Before / After AI Workflow Audit Example

This example shows how Mary Wang turns a vague automation idea into a paid-work-ready workflow.

The example is fictional, but the structure is the same as a real anonymized case study.

## Before

The founder says:

> I want to use AI to automate client reporting.

Current situation:

- Client notes are scattered across chat, email, spreadsheets, and screenshots.
- Reports are written manually every Friday.
- The founder is unsure whether to use ChatGPT, n8n, Zapier, Notion, or custom code.
- No one has defined what the final report should always include.
- The founder is worried AI may invent details.

Problem:

This is not ready for full automation. The workflow boundary is unclear.

## Audit Questions

Mary asks:

1. What is one real input sample?
2. What does a good final report look like?
3. Which parts must stay human-approved?
4. How many hours per week does this cost?
5. What would make the report unsafe or embarrassing?

## After

Recommended first workflow:

```text
Client notes folder
  -> AI draft summary
  -> human review checklist
  -> final weekly client update
```

Human approval stays required for:

- client commitments
- numbers
- complaints
- deadlines
- final sending

First build:

- one folder structure
- one report template
- one AI drafting prompt
- one review checklist
- one handoff doc

# Direct Conversion Templates

Use these when public proof exists but no one is becoming a qualified lead.

## 1. Public Reply With Sample Ask

```text
This looks like the kind of artifact where one real sample would clarify the next step.

If you have a draft evidence matrix, dashboard screenshot, export, checklist, or report shape, I would test it against three questions:

1. What decision should this artifact support?
2. What evidence source proves each green status?
3. What should the reviewer not infer from it?

Without a sample, the safest next step is to define one row or one bundle and make it reviewer-safe before building the whole dashboard.
```

## 2. Direct Reply After Engagement

```text
Thanks for the context. The fastest way to make this concrete is one sample artifact.

If you can share a redacted evidence matrix, dashboard screenshot, export, checklist, or report draft, I can point out what it currently proves, what is missing, and what the smallest useful cleanup should be.
```

我现在做一个小范围 Evidence Pack Triage：看一个样本，24 小时内给出缺字段、风险点和下一版结构。首批案例价 RMB 399，可用微信/支付宝，前提是允许匿名整理 before/after。

## 5. Follow-Up After No Sample

```text
Following up once.

If this is still useful, the next step is just one redacted sample: matrix, dashboard screenshot, checklist, report, export, or evidence bundle.

Without a sample I would not quote a build, because the risk is designing around the wrong reviewer decision.
```

Current evidence:

- 47 tracked leads.

- 0 audit offers sent.

## New Wedge

Move from:

```text
Useful public comment -> maybe someone replies -> maybe they send a sample -> RMB 699 audit
```

to:

```text
Find active evidence/compliance/audit/dashboard work
  -> ask for one concrete artifact
  -> offer RMB 399 first-client Evidence Pack Triage
  -> deliver 24h teardown
  -> convert to RMB 1999-4999 build
```

Evidence Pack Triage.

- RMB 399 for the first 3 real buyers who allow anonymized before/after case study permission.
- Standard price remains RMB 699 after the first 3.

Delivery:

- 24 hours after payment and materials are confirmed.

Best input:

- evidence matrix
- audit dashboard screenshot
- compliance checklist
- SOC2/control evidence index
- audit export
- evidence bundle
- reviewer package
- AI monitoring dashboard spec

Output:

- what the artifact currently proves

- missing fields
- stale/evidence-risk areas

- smallest build that would make it more useful

## New Daily Rule

Every daily run must include at least one of these direct conversion actions:

- Ask an engaged lead for one concrete sample artifact.
- Send the RMB 399 Evidence Pack Triage offer after a real sample is offered.
- Prepare a platform listing or post that directly sells the triage.
- Follow up on a buyer-like issue with a specific sample request.

If the day only creates more public comments, the day is incomplete.

# AI Workflow Audit Checklist for Non-Technical Founders

Use this checklist before paying anyone to automate your workflow.

## 1. What Are You Trying To Repeat?

Write the task in one sentence:

> Every week, I need to...

Good examples:

- Turn client notes into a report.
- Review a folder of images and pick the best ones.
- Convert messy chats into a weekly work log.
- Check whether a repo or tool is useful.

Bad examples:

- Use AI more.
- Automate everything.
- Build an agent.

## 2. What Is The Current Input?

List the materials you already have:

- Files
- Folders
- Screenshots
- Spreadsheets
- Chat logs
- Emails
- URLs
- Voice notes
- Existing prompts

If the input is not clear, the automation will not be clear.

## 3. What Is The Current Output?

What should exist at the end?

- A document
- A cleaned folder
- A summary
- A list of leads
- A report
- A webpage
- A spreadsheet
- A decision

Write one example of a good output. If you cannot show an example, describe what "good" looks like.

## 4. Where Does The Workflow Break?

Mark the top three problems:

- Too many repeated steps
- Too many files
- Hard to know what matters
- Results are inconsistent
- Requires technical setup
- Takes too long
- Easy to forget steps
- Depends on one person's memory
- Output is hard to review

## 5. What Should Not Be Automated?

Some steps should stay manual:

- Payment approval
- Password entry
- Legal judgment
- Medical judgment
- Financial advice
- Final client approval
- Publishing under your name

Automation should prepare the work. It should not remove judgment where judgment matters.

## 6. Smallest Useful Automation

Choose one:

- Make a checklist.
- Make a template.
- Make a script.
- Make a static page.
- Make a report generator.
- Make a repeatable AI prompt workflow.

The first build should save time within one week.

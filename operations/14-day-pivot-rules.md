# 14-Day Pivot Rules

Mary Wang should not repeat ineffective activity just because the website exists.

## If There Are No Engaged Leads

Problem:

The audience or reply angle is wrong.

Actions:

- Stop linking the service page in first-touch comments.
- Use only diagnostic checklists.
- Switch from general AI automation to one niche:
  - n8n workflow cleanup
  - client reporting automation
  - folder/repo inspection
  - AI agent auditability

## If There Are Engaged Leads But No Qualified Leads

Problem:

People find the advice interesting but do not feel enough pain.

Actions:

- Ask sharper follow-up questions:
  - What task repeats every week?
  - What does one failed run cost you?
  - What file, chat, or form starts the workflow?
  - What output would save time this week?
- Stop talking about "AI workflows" in abstract terms.
- Use concrete examples from `proof/sample-ai-workflow-audit.md`.

## If There Are Qualified Leads But No Payment

Problem:

The offer is not trusted or the price feels risky.

Actions:

- Offer first-client discount: RMB 399.
- Require permission to publish anonymized before/after.
- Shorten delivery promise to a very specific artifact:
  - workflow map
  - risk list
  - smallest automation recommendation

## If There Is Payment But No Mini Build

Problem:

The audit did not make the next build obvious.

Actions:

- Add a one-page `Mini Build Quote` to the audit delivery.
- Include price range, timeline, and exactly what will be built.
- Ask one yes/no question: "Do you want Mary to build this first workflow?"

## Kill Criteria

Stop or change the current wedge if, after 30 days:

- 100 useful public interactions produce zero qualified leads, or
- 10 qualified leads produce zero paid audits, or
- 3 paid audits produce zero useful follow-on build opportunities.

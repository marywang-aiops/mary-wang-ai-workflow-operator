# ClawHub / OpenClaw Listing Copy

## Skill Name

ai-workflow-audit

## Short Description

Audit messy AI workflows and produce plain-language next steps.

## Listing Description

This safe instruction-only skill helps an AI agent inspect a messy workflow, folder, repo, or automation idea and produce a non-technical audit report.

It focuses on:

- current workflow summary
- input/output clarity
- repeated manual steps
- risk boundaries
- smallest useful automation
- plain-language next steps

The skill does not require secrets, payment credentials, shell commands, crypto actions, or destructive file operations.

## Safety Notes

- Do not request passwords or private keys.
- Do not run unknown scripts during an audit.
- Do not delete or move files unless the user explicitly asks in a separate task.
- Keep final recommendations understandable to non-technical users.
